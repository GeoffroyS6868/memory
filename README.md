# Memory

Un bloc-notes local : on tape une idée ou une chose à faire en bas de l'écran, elle devient une bulle qui s'envole et flotte, avec les autres, dans un espace 3D en arrière-plan.

Les données restent dans le `localStorage` de votre navigateur, rien n'est envoyé.

## Démarrage

```bash
pnpm install
pnpm dev
```

Conception détaillée dans [`docs/design.md`](docs/design.md).
